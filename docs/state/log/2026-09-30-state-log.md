## What changed

Amit was hitting merge conflicts on nearly every task, almost always in `docs/project-state.md`:
every branch edited the 590-line "Current handoff" section and inserted its checkpoint at the
same line directly below it. This task introduces `docs/state/log/`, an append-only directory
where each task adds one new file per checkpoint and the handoff is derived by
`scripts/state-handoff.mjs` (`npm run state`, `npm run state:check`). `docs/project-state.md` is
frozen as history; its handoff was copied verbatim to `2026-09-30-handoff-snapshot.md` and each
open topic got its own seed entry. `AGENTS.md` §2, §7.1 and §8, `CLAUDE.md`, `README.md` and the
`/start-task` skill were updated, and the missing `/finish-task` skill was added.
